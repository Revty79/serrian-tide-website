# Atlas surface material collection v1

The original texture files in this directory are Poly Haven assets released under CC0 1.0. They are not proprietary satellite imagery. The website serves these bundled files locally and does not contact Poly Haven at runtime.

The files are unmodified source JPGs. sources.json records original download URLs, byte lengths and SHA-256 hashes. Runtime mipmaps, coordinate-anchored stochastic blending, visual mapping scales/tints and terrain lighting are Serrian Tide presentation choices; none becomes numerical elevation.

The source files and this versioned directory are retained as published artwork. Future asset replacements require a new explicit asset version.
