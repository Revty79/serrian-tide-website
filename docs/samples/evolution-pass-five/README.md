# Evolution Pass 5 — Form print review

These PDFs use disposable demonstration Characters, saved Race Forms and real Chrome print rendering. They contain no live campaign data.

- [Character with three selected Forms](character-form-packet.pdf) — 11 pages.
- [Race NPC with three selected Forms](race-npc-form-packet.pdf) — 11 pages.
- [Player printing a Locked Form reference](player-locked-form.pdf) — 5 pages.

The first two pages of each packet are the ordinary Character sheet. Each selected Form then starts its own reference section, with continuation pages as needed for complete authored mechanics. Available, Locked and G.O.D. review statuses do not change through printing. Current damage stays on the Character.

[Contact sheet 1](form-print-contact-1.png), [contact sheet 2](form-print-contact-2.png), [contact sheet 3](form-print-contact-3.png).

[Automated PDF checks](form-pdf-verification.json) covered all 27 pages, 196 paragraphs and 185 table rows, page bounds, readable text, identifiers, pagination and independent Form starts. Full-resolution page images were inspected. Physical printers, Firefox and Safari were not exercised.

See the [Pass 5 report](../../architecture/evolution-pass-five-report.md) for implementation, tests and rollout requirements.
