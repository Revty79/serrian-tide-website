- `preservation.json`: baseline, protected-file manifest and unchanged storage/generation/business/gameplay/migration foundations.

- `results.json`: full disposable migration/build, retained information creator/History/calendar/role/privacy/HTTP boundary regressions and unchanged legacy/gameplay table snapshots.
