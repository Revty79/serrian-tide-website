# Actual website land-mask proof

All geometry and artwork in this proof were made through ordinary website controls in the owned disposable target: Create map, explicitly associate a fictional plane, Draw an island, Add hole, save, draw two more separate islands, then paint a retained v1 forest stroke across sea, land, the opening and the island inside it. The new map pins `island-ink-wash` revision 1. Its straight rectangular boundaries intentionally make clipping measurable; this is not an art-quality sample.

The production browser normalizes the actual forest fill through a 1-pixel canvas before pixel comparisons. It finds 14,632 full-color terrain pixels on authorized land and zero in water or the enclosed opening. The database still contains the original cross-boundary stroke, beginning at x=60 and ending above x=1900. A shared transient mask controls display without trimming originals.

This is bounded composition and compatibility evidence. It does not establish the final 14-asset library, full generated/manual first-island journeys, recovery, performance budgets or owner testing readiness.
