# C2/C3 repair application evidence

These are actual authenticated ordinary-view screenshots from the populated **restored disposable installation**, running the final Node 22 production build with a separate recovered private asset volume.

- `combined-desktop.png`: existing Earth at the worldwide overview, with numerical elevation tint, dated WorldCover classifications and preserved geographic vectors/labels.
- `combined-phone.png`: 390-pixel native-touch browser emulation after Zoom in and Pan east, with both raster layers, class legend, source credits and usable navigation. It is a full region capture and therefore deliberately tall; this is browser emulation, not physical-phone hardware acceptance.

The ESA copyright correction is visible in the classification credit. Class colours retain their scientific meanings; surrounding colours use the existing saved shared theme. No source values, dates, classifications, map identities or Atlas artwork were rewritten. The display remains the existing Geo C viewer; Geo D's unified Map Maker/deep-zoom work is recorded separately and is not implemented here.
