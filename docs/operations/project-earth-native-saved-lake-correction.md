# Project Earth Pass 1: editing a saved lake

Native Earth authoring exposed a gap in the existing lake controls: a saved lake's corners could be moved, inserted or removed, but a creator could not add another island outline through its drawing workshop. Recreating the lake would discard its identity and connection history. This correction opens the existing workshop for the selected saved lake, retains its identity, and accepts the revised shoreline through the ordinary water draft and explicit Save water changes action.

The creator can add an island, redraw only the selected outline, or cancel. Redrawing an outer shoreline retains the other island outlines. Untouched original rings retain their exact accepted World coordinates, avoiding a coordinate round-trip. The selected terrain source must contain the entire lake; otherwise the editor explains how to choose a suitable source. The current lake is checked again before its preview enters the draft. Existing frame, crossing, overlap, review, source-pin, permission, recovery, history and save guards remain in force. Connected river nodes and edges stay retained for review.

This reuses the existing 1,024-total-corner and 32-island workshop budget. Ordinary terrain polygons still permit 256 corners. There is no migration, server endpoint, numerical engine, renderer, authentication, deployment configuration or capacity change. Water outlines do not carve a basin, establish an actual water level or certify drainage.
