## General correction and retained guards

The established asynchronous numerical sampler still returns a Promise and
accepts existing asynchronous loaders. A shared internal entry point can return
an immediately available number when the source and its native samples are
already verified in the request. Actual metadata and object reads remain
asynchronous. Bilinear arithmetic, clamping, wrapping and explicitly pinned
earlier-parent reconstruction stay unchanged.

The existing request-local reference cache gains a synchronous peek. Undefined
means uncached, while null remains an authoritative cached miss. Peeking uses
the same source/revision keys, 1,024-reference capacity and LRU order. Numerical
sources retain verified metadata after loading; decoded tiles remain in the
same 128-entry request-local cache. Required missing fine data still refuses.
No global elevation arrays or new full-map mask are introduced.

Coast and reconnection audits avoid artificial awaits for ready numbers. Their
sample visits, work counters, cancellation checks and periodic yields remain.
The 32 MiB workspace, 262,144-cell workspace, 8,388,608-step audit and 30-second
deadline are unchanged. Accepted writers, atomic history, licensing, permissions,
renderer, schema, authentication, configuration and deployment code are byte-exact
to the parent release.
