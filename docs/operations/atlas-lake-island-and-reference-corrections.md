## Correcting an unused reference

The existing Sources & rights panel now offers an explicit owner correction with a reason and attestation. The authoritative transaction requires:

- Ordinary owner editing control and a current authenticated session.
- An explicit non-original reference with exactly one World attachment and no imported/material uses.
- No approval at any time, source ancestry or derived material.
- The original accepted attachment audit and no accepted World content write after it. Undo does not erase an intervening derivation.
- No prior withdrawal, except exact replay of the same original request.

An immutable receipt in the existing World audit excludes only that proved-unused explicit reference from active enforcement and native-copy inputs. Every evidence, review, use and ancestry row remains append-only. The withdrawn item stays visible with its hold and correction reason and cannot be reattached to that World. No review is cleared, no customer/output right is granted, and used/approved/imported/derived sources remain non-withdrawable. Older application versions conservatively see the original held reference again.

There is no migration, format, capacity, authentication/configuration, owner service restart or deployment change. The correction uses existing permissions, audit storage and paired-recovery mechanisms.
