# Atlas Stage 8 export and print capability matrix

The active Worlds → Atlas native editor has **Export / Print** beside its existing map actions. World/Region uses the viewport controls, Town uses the lower-right canvas action, and interior/underground/craft/deck uses the first action in the scrolling drawing-tools row. These placements retain the original editor headers and drawing height. The action opens a separate, non-destructive preparation dialog. It reads the accepted saved source; unfinished drawing, proposals and retry/recovery packets remain in their editor. The earlier illustrated Map Studio export remains available unchanged. These native editors do not use that older SVG workspace wrapper, so their native map controls are the entry point.

| Native family | Saved source and coordinates | Appearance and meaningful layers | Digital and print output |
| --- | --- | --- | --- |
| Numerical World | Accepted current numerical objects/refinements, or explicit retained timeline/year/version; physical World metres and continuous wrapped X | Saved/custom appearance and the six existing numerical appearances; relief, materials, environments, water, installed artwork, ordinary labels/positions, eligible saved image composition; political boundaries only from an explicit retained dated layer | PNG, JPEG, hybrid SVG, fit/true-scale/poster PDF; whole extent or adjustable physical crop |
| Region, including nested Region | Exact linked numerical source and saved polygon; explicit selected parent-World version for historical geography; no new independent grid or inferred modern footprint | Same numerical styles and layers, clipped to the saved Region polygon; optional actual Region boundary | Same formats and layouts; crop remains in the source World's metre frame, including seam crossing |
| Town / City | Accepted independent Town geometry and physical local extent; pinned numerical backdrop when authorized and retained | Original Town road/building/decorative painters; ground/water backdrop, districts, roads, buildings, walls, drawn water, landmarks, labels and eligible image composition | Same formats and layouts; transparency can omit ground while retaining painted features |
| Building floor | The one explicitly selected independent floor and its captured building footprint/frame | Original floor painter; rooms, walls, openings, furniture, transitions, annotations and eligible image composition; the existing rigid building working-grid alignment is reused and described in output metadata | Same formats/layouts in aligned local metres; no exterior rotation or persisted floor coordinate is rewritten |
| Underground level | The one explicitly selected cave/dungeon/sewer level; its independent local metre frame | Original underground painter; ground, chambers, walls, openings, passages, environments, furnishing, transitions and annotations, with secret content removed | Same formats/layouts; other levels are exported deliberately as separate sources |
| Craft / vehicle exterior | Accepted independent exterior surface and physical frame | Original shared native floor/surface painter for the saved outline, compartments, walls, openings, furnishings, transitions, annotations and eligible composition | Same formats/layouts; no inferred compass, motion simulation or gameplay scale |
| Craft deck | The explicitly selected independent deck, its order/height and physical frame | The actual saved deck plan and original native painter; independent from the exterior and other decks | Same formats/layouts; no implicit deck stack or substitution of another deck |

All families support saved historical export where the selected retained appearance exists. Unknown coverage is identified explicitly. Missing retained parent geography/artwork is never replaced with today's source. Ordinary Canon content, independent personal variations and authorized collaboration scopes use the same ordinary projection and fresh authorization. Administrator review grants no protected export mode.

PNG preserves alpha where the actual painted content permits it and carries DPI/source metadata. JPEG is opaque, with adjustable compression and DPI. The SVG is explicitly **hybrid**: native map illustration/terrain is embedded raster; measurement grid, scale, axes and complete source text are SVG vectors. It has no external image URL or executable content. It is not advertised as an all-vector terrain, Town or floor drawing. PDF uses sequential high-quality raster pages of the actual map with Unicode source text rendered on the page; that page text is not a selectable/searchable PDF text layer. This avoids a second renderer and preserves the original native appearance. PDF is the physical-print authority; image/SVG pixel dimensions do not by themselves establish printer calibration.

Image presets run from 1,200 to 8,192 pixels on the long edge. Custom map surfaces must fit both the 8,192-pixel edge and 24-megapixel bounds, including the added complete-credit footer in the final image. A preset that exceeds either bound fails with recovery guidance. DPI choices are 72, 96, 150, 300 and 600. More output pixels do not create additional numerical source accuracy.

Paper sizes are Letter, Legal, A4, A3, A2 and Tabloid, portrait or landscape, with 5–50 mm margins. Fit-to-page calculates and labels its resulting scale. True scale uses an explicit 1:N denominator and either fits or requires deliberate poster output. Poster pages have a constant scale, row-major order, 0–20 mm overlap and optional alignment marks. The preview and generated PDF use the same plan; short source information fits in the page footer and longer complete credits use source pages. The total limit is 24 pages, each within the same 24-megapixel/8,192-edge bounds, and 64 MiB per file. Higher DPI on large paper can exceed those limits and is rejected before allocation.

Selection is a separate accepted-map canvas: draw a new box, move/resize it, or enter metre bounds, with independent pan/zoom and Fit Entire Map. Wrapped World crops show and accept adjustments from either visible seam portion without changing their continuous physical span. The modal locks/restores document scrolling and styles. Entire Map and Selected Area are distinct; no current-editor-viewport shortcut is offered. Physical grid spacing is explicit in metres, limited to 4,000 lines without silently changing it; display units are m/km/ft/mi. Scale bars and optional X/Y indicators use those coordinates. The axes are not an invented compass or a Tabletop movement rule.

Uploaded artwork is off by default. Inclusion requires an explicit permission-to-distribute choice and exact ordinary asset-version access, including Assets scope. Export-only sanitized WebP derivatives preserve up to a 4,096-pixel edge without upscaling; original metadata, private filenames and storage paths are never returned. Decoding is serialized and bounded, individual encoded images are limited to 8 MiB, and the separate export image cache to 72 MiB decoded. The original editor's 24 MiB image cache and every existing authoring/rendering gate remain unchanged. An unusable or confidential credit fails inclusion with a safe explanation; it does not expose the private credit text. Required valid credits are complete.

Rendering uses the existing CPU Canvas2D painters in 1,024-pixel output tiles, bounded numerical batches and short yields. Cancellation releases job caches, canvases and object URLs. This is a bounded output path, not a guarantee that an ordinary browser can allocate every permitted worst-case surface while other applications consume its memory. Allocation/encoding/source failures withhold the output and retain the map/draft. There is no permanent export record, publication link, automatic download sharing, protected-content output mode or new migration.

Exact technical receipts, failed attempts, source preservation and publication belong in the [Stage 8 delivery report](worlds-atlas-export-print-s8-delivery.md). Owner/Ember usability and artistic acceptance, physical-device behavior and printer calibration remain separate from automated technical checks.
