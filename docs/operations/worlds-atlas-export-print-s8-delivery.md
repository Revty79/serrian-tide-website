## Delivered behavior and architectural decisions

Every active native Atlas editor has **Export / Print** in its existing map actions: numerical World/Region, Town, floor, underground and craft/deck. A separately loaded native modal prepares accepted saved content while retaining the editor's current tool, unfinished drawing, drafts, previews, retry packets and local recovery. It provides entire-map or adjustable physical-area selection, independent zoom/pan/fit, explicit new-area versus move/resize actions, relevant styles/layers, resolution/compression, DPI, measurements, optional source presentation and actual paper/poster preparation. Wrapped selections keep continuous metre bounds and show both visible sides of the World seam. Native wheel input cannot move the underlying page; document styles and the same-page scroll position are restored on close. Hideable desktop/tablet/phone controls retain the 400-pixel phone drawing gate.

The [capability matrix](worlds-atlas-export-print-s8-matrix.md) specifies all seven families, formats, coordinate frames, styles/layers and limits. PNG supports alpha where painted content permits; JPEG provides compact opaque output. SVG is explicitly hybrid: actual native map raster plus vector measurement overlays and complete source text, with no external image URL or executable content. PDF contains actual rendered map pages with exact paper dimensions, fit or deliberate true scale, constant-scale row-major poster pages, overlap/alignment marks and full source information. Preview and final PDF share one plan. Short credits fit the footer; longer credits receive source pages. No editor/navigation interface is printed.

`cartography-export.ts`, `atlas-geographic-export.ts` and `map-export-layout.ts` remain unchanged. Their illustrated SVG workspace/2,000 by 1,200 PNG and geographic/raster authorization stay functional. Active numerical/native editors do not use that legacy Map Studio wrapper, so their existing native action bars are the Stage 8 entry point. No retired route, separate Studio or second mapmaker is activated.

Rendering orchestrates the original CPU Canvas2D painters in bounded tiles; terrain, roads, rooms, underground and craft engines are not replaced. Numerical maps reuse all six existing appearances and saved custom appearance. Floors reuse the existing working-grid alignment from the captured building footprint/frame, including saved image placement. The output describes that coordinate mapping; canonical geometry, exterior angle and identities are unchanged. Regions use their actual saved polygon. Political boundaries use the retained ordinary dated layer/year, without inferring today's politics.

Current accepted sources use repeatable-read, read-only projection without creating an appearance. Historical exports reuse Stage 7C's existing projector inside the same ordinary checked context. Editing-head selections are resolved and pinned before projection. Explicit parent-World geography belongs to the normalized source/hash/dependency metadata. Timeline/year/version, map-family identity, exact artwork and known/unknown coverage remain explicit; missing earlier geography is never substituted with today's data. A reference without a retained source requires either a retained selection or an explicit switch to current saved content without a historical claim.

The only Stage 7C producer change exposes its existing internal projector as `projectAtlasMapConsumption` and updates its three call sites. Public schema, endpoint behavior, ordinary projection and safeguards remain unchanged. Its original contract suite is rerun.

The implementation is confined to the new `src/features/worlds/atlas-export*` modules/tests and GET-only `src/app/api/worlds/[worldId]/exports/route.ts`; the five native editor launchers; the read-only history-context accessor and existing projector export. Six `worlds-map-export-*` scripts provide disposable source/browser/security, output inspection and preservation checks. The remaining changes are generated-evidence ignore rules, this report, the capability matrix and the Stage 8 AGENTS receipt. Existing export engines, dependencies, authentication, data formats and migration files remain unchanged.

## Permissions, attribution and reliability

Exports always use ordinary content, including Owner/Administrator review. There is no protected-source output mode, public publication URL or scope escalation. World/family/history/appearance/Assets scopes remain authoritative. Every resource/tile/image request and final delivery rechecks current access and the exact source hash. Changed sources are withheld rather than replaced; session/account identity is checked again. Confidential notes, protected geometry/labels, private filenames/paths, original EXIF, credentials and private URLs are not embedded.

Uploaded artwork is off by default and requires an explicit permission-to-distribute choice; exportability grants no license. Exact authorized versions become verified, metadata-free, export-only WebPs up to a 4,096-pixel edge without enlargement. No derivative is persisted. Decoding is serialized, encoded images are bounded to 8 MiB and a separate decoded LRU to 72 MiB; the original editor's 24 MiB cache is unchanged. Invalid/confidential credits fail inclusion safely without returning their private text. Required legitimate credits remain complete. Credit URLs must be clean/public; filesystem paths, internal hosts and credential/query/fragment URLs are withheld rather than partially rewritten.

Creator attribution comes from the actual original accepted version/creation operation and account display identity, not a hardcoded Revty79 string or guessed current owner. Canon and independent personal variation provenance stay distinct. Title, creator/provenance presentation, saved/historical context and dimensions are optional; required credits and unknown-coverage warnings remain. No permanent branding watermark is imposed.

A map/image/page surface is bounded to an 8,192-pixel edge and 24 megapixels; the image footer counts toward the final limit. Hybrid SVG is bounded to 32 MiB, files to 64 MiB, PDF to 24 total pages, metadata to 24 MiB, tile batches to 32 verified objects and grids to 4,000 lines. Oversize/failed/canceled work gives recovery guidance rather than silently reducing content, quality, spacing or credits. Jobs release caches, canvases, decoded images and object URLs. Changing export settings cancels an in-flight file and retains the new choice. Layer switches also feed the original appearance painters, so hidden hydrology/environment data is not baked into an alternative style. World craft poses use the existing native marker painter and exact ordinary current or retained marker metadata, with no current-day fallback for history. No export records/preferences, source captures, ownership changes or historical revisions are written.
