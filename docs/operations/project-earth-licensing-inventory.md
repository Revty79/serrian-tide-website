## Required remediation and owner-review items

1. **Stop held-source construction and release now.** This audit's holds are operational/documented, not hidden database edits or a claim of automated enforcement. Preserve every accepted version, reference file and protected checkpoint. No deletion, reset, source relabeling or account/permission change is proposed.
2. **ODbL special review is unresolved.** Before any resumed use, document the actual combined/derivative/collective database design, what customers receive, Produced Work credit, required data/access offer and whether obligations are compatible with the intended proprietary geography. Do not assume an attribution-only solution or that application code itself must become ODbL. A decision to publish/license a database component separately is a major owner decision, not an automatic workaround. The no-paid-source alternative is independently verified PD/CC0/compatible official boundaries; no accurate free replacement for all 564 records has yet passed review. Natural Earth's coarser outlines cannot silently replace Benin subdivisions or erase the short Kazungula border.
3. **Replace the Esri-dependent lower-Volga guide independently.** Use a separately verified no-cost source, such as USGS-distributed Landsat data whose [official reuse statement](https://www.usgs.gov/faqs/are-there-any-restrictions-use-or-redistribution-landsat-data) permits use/redistribution, after scene, access-channel, date and resolution checks. Existing OSM is not a cleared fallback. Review independently and apply an ordinary visible native revision preserving original identities/history; do not reuse the held 45-point guide and call it independent. No replacement has been authored.
4. **Replace or obtain a compatible no-cost grant for ANIDA-derived Patagonia.** An exact grant must cover the actual ecological layer and derivatives, not another Argentine dataset. Otherwise find an independent accurate PD/CC0/compatible reference and use visible revised environment authoring. No verified replacement or new grant currently exists. Credits cannot fix NC/ND rights.
5. **Resolve other factual/extract rights and exact source gaps.** Preserve current truthful provenance. Natural Earth's PD fields and independently dated [Wikidata structured CC0 data](https://www.wikidata.org/wiki/Wikidata:Licensing) are potential metadata alternatives; neither automatically validates their accuracy or licenses linked third-party content/Wikidata prose. Do not claim changing a citation removes earlier derivation. No new data from these candidates has been downloaded/incorporated in this audit.
6. **Complete actual source lineage/credits and enforcement before release.** Reuse existing immutable source/appearance/history/export mechanisms; design a review record distinct from a supplied license string and propagate mandatory notices, modification statements, revocation/holds and exact source pins through every offered view/output. Never discard accepted sources or create a duplicate geography system as a licensing workaround. Tests and normal visible validation must prove this across mixed-source maps, history, copies, crops and all output formats before the product-compliance gate can pass. This audit adds policy/documentation only; it does not claim that runtime work is implemented.

The owner's earlier instruction requires stopping at critical verification failures. Accordingly safe-source findings do not resume Stage3 while the existing Stage2 licensing/attribution gate is unresolved. No Production, Canon, settlement or Tabletop work follows from this report. Geographic/artistic approval remains separate from technical and licensing review.
