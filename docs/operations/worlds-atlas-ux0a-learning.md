This checkpoint adds integrated learning and records functional website journeys using the retained three-subject library. It is not final artwork acceptance or owner-testing readiness. ## Delivered behavior

Empty generic maps open Create land. Its two equally visible actions lead to the existing seeded geographic generator and manual geographic drawing. The creator first reviews and explicitly associates the fictional plane with visible 0–2000 by 0–1200 map-unit bounds, or chooses the existing supported alternatives. No World topology or duplicate decorative coastline is silently created.

Help includes an optional nine-step Create Your First Island lesson in the actual Studio. It opens real tool panels and observes the actual authorized surface, saved source heads, a newer coastline revision, terrain artwork, illustrated river, persistent place/linked label, independent dirty domains, saved drawing/source identities in a new editor visit and a successful visible PNG export. Generated and drawn branches converge on the same source editor. Review-step navigation does not fabricate verified steps. Final verification requires the real content, a newer source revision, reopen and a current export with no dirty domain.

The lesson can close/resume while the map remains editable. A small map/World/timeline-scoped session record retains lesson position, chosen branch and verified identity metadata. It stores no map-content draft and does not replace Save and recovery. React's external-store subscription keeps browser storage/hydration separate from map state; storage failure leaves the lesson usable in the current editor and preserves map content. Opening help and switching panels retains pending inspector fields, selection and each editor's undo/redo.

Searchable reference covers the empty-World starting path; surfaces/coordinates/sources/versions; generation and manual creation; components/openings/source revisions; illustration placement/painting/editing; rivers; persistent places/labels; independent saves/retry/recovery; numerical elevation/classification; reopening/export; retained classic tools, History/Connections and connected scales; pointer/touch/keyboard operation. Topics have plain-language search terms, worked examples, why-it-works feedback and links to actual applicable tools. Instructions were checked against the existing controls. Geographic vertex selection/arrow nudges are documented accurately rather than advertising a nonexistent numeric source-coordinate form.

Paint artwork, Places and labels, Edit geography and Create land are labeled within the existing workspace. Classic decorative coast/sculpt/trace, paths, symbols, labels, legacy generation/variation, History, Connections, layers and specialized editors remain reachable. New island-style editors start with a lighter 45-unit brush, 90-unit spacing and one mark per sample; saved strokes and v1 editor defaults retain their original values. Narrow layouts offer Expand tool settings for reading and editing within the viewport. Escape/close returns focus through the existing Studio behavior.
