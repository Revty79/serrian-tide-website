# Native variable landform profiles

The original ridge and valley workshops use one width and one relative change or one-sided elevation bound along a path. A minimum-height ridge cannot lower an existing uniform crest. The Central Andes working pilot exposes why creators also need varying crest heights, widths, saddles and continuous joins, with explicit protection of accepted water and finer terrain.

**Shape Landform Profile** is available under Sculpt → Landforms & areas. Draw or move native path points and edit each point's physical full width and metre elevation. Shape mode can raise and lower land toward the profile; Minimum and Maximum retain heights beyond their respective bound. Smooth interpolation varies width and elevation between points. Competing segments blend their target heights continuously at bends and intersections; their effects use a maximum envelope instead of accumulating several changes. Optional end and selection blends meet the surrounding accepted terrain inside the selected footprint.

The tool uses the existing advanced workshop, operation worker, accepted-context loader, browser draft recovery, numerical preview, affected-geography review, native acceptance, original-request retry, autosave and Undo/Redo. **Fit selected area** makes a small proposal inspectable without manually navigating from the whole World. Profile acceptance also waits for numerical rendering readiness.

The existing server recomputes the proposal from accepted samples, its original water/site/volcano context pin and exact operation parameters before accepting the submitted tiles. Ordinary permissions, source revisions, finer-source exclusions, history and retained requests remain authoritative. The accepted operation is a normal manual source with immutable advanced provenance; the heights remain editable with ordinary terrain tools. Existing manual serialization and all earlier operation defaults remain compatible.

Sea samples and their eight neighboring interpolation supports remain exact. Saved lake/wetland beds, finer source exclusions, settlement supports and optionally retained manual heights remain exact. This does not rebase finer sources or change their old parent pins. A protected interface can constrain a proposed landform; inspect and correct its joins through the appropriate native source rather than assuming automatic cross-resolution propagation. Water levels and routes remain separate explicit native edits.

Each physical width must span at least two native samples. Up to 128 path points share the unchanged 262,144-cell, 8,388,608-work, 32 MiB numerical-buffer and 30-second execution guards. Unsupported proposals refuse without downsampling or changing accepted terrain. A tiny selection on a 4096-square source still exceeds the existing memory budget. Adjacent numerical step/slope diagnostics aid review; they are neither acceptance thresholds nor an elevation-accuracy certificate. End blends, geometric interpolation and visual exaggeration create no additional samples.
