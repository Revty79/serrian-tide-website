The production source filesystem audit finds filesystem persistence only in `terrain-storage.ts`, `atlas-asset-storage.ts`, `raster-storage.ts`; `raster-numerical.ts` opens retained originals read-only. Browser Blob/download and localStorage/IndexedDB paths remain device-local. Other application data is PostgreSQL-backed. Audit tests guard this list so an additional filesystem writer requires review rather than silently escaping future backups.

All three private roots must stay outside `public`, independently of whether this particular release already rejects a bad path. Do not expose snapshots, source originals, private files, environment configurations or signing/encryption keys through the website. Backups contain confidential accounts and histories even when file paths are content-addressed.

Existing coverage is deliberately reused: `terrain-backup-restore.ts` provides the retained CHECK-validator search-path correction; `readTerrainTile`/`readAssetObject` verify immutable objects; `raster-bundles.ts` verifies exact raster manifests, originals, numerical/categorical data and bounded hardlink layouts. Existing paired-restore tests cover database/terrain/artwork and real authenticated service reads, but do not constitute one complete operator workflow including raster, writer fencing, authenticated manifests, destination safety and encrypted transfer. The new workflow closes those gaps without adding another data authority.

External references: retained geographic provenance/license URLs and optional user avatar/content URLs preserve their database strings; remote bytes are not mirrored by a website environment snapshot. Operator-prepared import inputs outside the three runtime roots need separate archival if they are to be re-imported. No active object-store, mail-delivery, payment, webhook vendor or scheduled external worker was found in the production source. Chat/Tabletop live listeners use the same PostgreSQL authority; their heartbeat timers are not another persistence store. Provider dashboards, DNS/TLS, reverse proxy, firewall/VPN, operating-system locale/extension packages, SQL roles and secret-manager configuration are infrastructure dependencies, not application-data blobs. Browser unsaved work and these external systems remain explicitly outside automated snapshot capture.
