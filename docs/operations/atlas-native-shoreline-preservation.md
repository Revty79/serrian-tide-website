# Keep the saved sea shoreline during native relief edits

A land-only native area edit can retain every wet/dry classification while
moving the interpolated coastline. During Earth authoring, the western
Australian minimum-height edit raised 17 original dry shoreline supports from
200 m to 201–206 m. An isolated unchanged-kernel example reproduces 40 changed
shore supports with zero classification changes. Classification alone therefore
does not establish coastline preservation.

The area and ridge/valley workshops now offer **Keep saved sea shoreline** when
either saved-sea elevation filter is selected. It defaults on for a new filtered
operation. The original neighboring sample heights that support the saved sea
boundary stay exact, including diagonal neighbors and the wrapping seam. The
filter uses the original field and saved sea level throughout smoothing passes.
Unchecking it allows deliberate edge-height changes and requires a fresh
preview. All elevations retains its original operation and controls.

The optional checked-operation flag preserves exact legacy behavior when absent
or false. It adds no full-map protection buffer. Existing exclusions, protected
samples, numerical limits, cancellation, manual patches, saves and history keep
their guards. This is sea-boundary protection; the existing advanced operation
tools remain the appropriate protected workflow for lake/wetland beds and other
geographic supports. It neither invents hydrology nor decides that every
below-sea basin is wet.
