# Native coverage correction within Project Earth Pass 1

## Reproduced limitation

The ordinary Atlas controls refused a prospective island detail that overlapped an existing area at the same level. Selecting that existing area as parent also refused bounds extending beyond its frame. Its inherited edge was protected, so neither path could author a continuous coastline across that boundary. Both refused proposals were retained privately; neither created terrain. This correction supports continuing the authorized native Earth authoring pass.

## Native editing behavior

Select an accepted terrain detail, choose **Extend coverage**, select larger supported sample dimensions and position the retained grid using **Added samples to west/north**. Preview and inspect the proposed bounds, then choose **Accept extended terrain**. The same source identity gains coverage at its existing numerical spacing. Existing samples retain their exact values and World positions; the added area uses the existing parent interpolation. This does not import geography or add fine features automatically.

Both axes retain their previous size or grow; at least one must grow. Offsets use complete 32-sample tiles. Supported dimensions, the 4096-axis advanced confirmation, resource budget, fixed World edges, parent containment and sibling exclusion retain their existing limits. Children keep their original parent revision pins. Their coverage remains protected. The new outer collar remains inherited; a former edge inside the enlarged area becomes eligible for ordinary sculpting.

Cancellation changes no accepted terrain. The first acceptance packet and its recovered retry use the same normalized bytes. An interrupted response can be retried after normal reload without adding another source. Older saved revisions retain their original geometry. Restoring one replaces its retained area while keeping coverage added afterward; Undo/Redo of subsequent edits continues through the existing save paths.
