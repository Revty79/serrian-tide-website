## Delivered behavior

The existing active Atlas **Switch Map** browser now includes Underground Maps. Sites have independent durable levels and may remain independent, adopt an existing permanent Place, or create a Place only through an explicit choice. Town buildings/landmarks/access points and building-floor transitions expose Create/Open/Connect Underground Map. No generated map creates commerce, creatures, Campaign changes or gameplay behavior.

Blank, constructed dungeon, natural cave, sewer and independent level-copy starts share editable source. Generation offers size, complexity, density, passage width, branches, material and seed, with revisable unaccepted previews. The editor supports rectangular/irregular/round chambers, path passages and tunnels, attached real wall gaps, doors/gates/windows, environment surfaces, furnishings, narrative details and travel markers. Direct movement, boundary handles, resize/rotation, archive/restore, Undo/Redo, visible save status, physical-metre guides and one translucent aligned reference use the retained floor geometry rules. Original floor/Town artwork, canvas and input engines remain unchanged.

Cross-map connections have their own identity and explicitly typed Town/interior/underground/World endpoints. One atomic record supports deliberately chosen two-way travel. Connecting never rewrites either arrival object or the interior `destination.floorId` contract. Marker anchors follow independently moved markers; explicit position anchors remain fixed. Navigation validates current ownership, World, source/target availability and regional footprints, preserves Town/selected entrance/regional context, and retains direct-link/reload return context. Archived destinations remain recorded with disabled travel and explicit restore/disconnection actions. Copied levels receive independent drawing IDs and no live connections.

Rooms, walls, openings, passages, environments, furnishings, transitions and annotations have independent visibility/locks. Gridless/square/hex guides affect new snapping only. Secret/G.O.D.-only features, dependent walls/openings and contained protected details are removed by the server-filtered ordinary preview; private notes are stripped. Preview/export uses that filtered document and grants no Player access. Owner authoring, explicit read-only Administrator review, other-G.O.D./Player/anonymous denial, private/no-store responses, readonly aliases, source bounds and optimistic revisions remain enforced on the server.

Recovery retains metadata-only drafts, unaccepted previews, drawing controls/points and exact canonical submitted requests. Lost acknowledgements lock the original request for exact retry. Independent-tab recovery retires acknowledged original bytes only when unchanged; newer other-tab work survives. Conflicts retain work until explicit comparison/discard. Corrupt/full local storage supports raw export; creation, drawing, map edits and retained connection operations participate in navigation/unload protection. Accepted history is immutable. Server lock checks cover objects, attributes and moves into another locked layer.
