# Creature incapacitation and death rewards

Authority: Brannan's 21 September 2026 correction after Adrian Vale received Fame for only one of two CR 2 Cats:

> if it is incapacitated or killed it should grant the xp and fame as if killed.

This supersedes the earlier death-only eligibility for Creature CR Fame.

- Incapacitating the whole Creature and killing it have the same reward eligibility and authored values: its existing XP value and its CR in Fame.
- Fame belongs to the credited Player Character. The existing G.O.D. XP distribution choices remain available; this ruling does not change how XP is divided.
- Award each reward once for the exact Creature occurrence in the encounter. Later death, repeated damage, retries, healing and re-incapacitation do not create another award for that same occurrence.
- Preserve the actual condition. An incapacitated Creature remains alive; granting rewards does not change its HP, mark it dead or create a kill record.
- A disabled limb alone is not whole-Creature incapacitation. Surrender alone is outside this correction; existing explicit NPC surrender rewards remain unchanged.
- Missing CR or uncertain credit still needs its existing G.O.D. decision. Reward calculations must not invent a value or a recipient.

The retained `creature-kill-fame:<participant>` receipt identity also covers incapacitation. Keeping this internal identity makes prior death awards and new incapacitation awards mutually exclusive. New evidence uses `defeatFame`; old `kill` evidence and immutable award receipts remain readable.

XP already accepted incapacitation before this correction. Fame now uses the same eligibility, triggers on the first supported damaging action that incapacitates or kills, and is also available through the existing closeout attribution controls. Health/death thresholds and combat timing are unchanged.
