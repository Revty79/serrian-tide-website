# Dedicated future Atlas tools

The owner-adopted [revised remaining Map Maker roadmap](worlds-map-maker-decisions.md#revised-completion-roadmap--adopted-2026-10-15) is the current D3–E sequence and five-standard completion contract. Settlement, interior, dungeon and connection systems described below already exist; preserve their historical pass descriptions and extend their usability, integration and output rather than recreating them. Development readiness and UX-0 owner acceptance come first; D3-B requires its own precise scope and separate authorization. The later Worlds cleanup, Phases 7–9, Advanced Map Studio and Comprehensive Historical Earth remain in their approved order.

The permanent [Geo D1-D5/E Map Maker decisions](worlds-map-maker-decisions.md) now govern the initial visual Map Maker, deep zoom, progressive geographic source resolution and later Advanced Map Studio boundary. Preserve existing connected-scale implementations and identities as those requirements are fulfilled; the C2/C3 repair records them only.

The user's permanent requirement is connected geographic scales: World → Continent → Region → City → Building → Dungeon Floor. Pass 3B implements continent cartography only. Scope labels do not establish these links, geographic distances or nested navigation.

Each future increment must independently deliver usable tools, complete migrations, preserved data, authorized server behavior and verified desktop/phone workflows. Stable World geography/location identities remain separate from map drawings and from the visual representation's scale.

1. Secure raster backgrounds: durable authenticated asset storage, file/size validation, private delivery, overlays, restoration and deployment persistence. Never infer vector objects from baked-in artwork. This remains a separate contained increment.
2. Pass 3C implements configured seeded generation and supported description interpretation using the same editable polygon, brush-stroke, path and label contracts. Creation provenance remains separate from manually edited source. No incompatible generated picture representation. See [native generation](worlds-atlas-generation.md).
3. Pass 3D adds [connected geography and exploration](worlds-atlas-navigation.md), using shared place IDs, represented-map associations and preferred connections. Pass 3E-A adds [dedicated settlement authoring](worlds-atlas-settlements.md): editable streets, building footprints, boundaries, overlapping districts and landmarks. Worlds remains standalone; these records do not create or link Heavens Towns, Shops, NPCs or Campaign objects. Future integration belongs to a separate dashboard VTT application, outside Worlds and Paths.
4. Pass 3E-B adds [dedicated building interiors](worlds-atlas-interiors.md): stable building-linked floors, multiple floor-plan representations, editable rooms/walls, attached openings, furnishings and explicit stair/portal navigation. It reuses World authorization and Atlas exploration without tabletop runtime integration.
5. Pass 3E-C adds [dedicated dungeon authoring](worlds-atlas-dungeons.md): independent sites and levels, editable chambers/caverns/corridors, attached openings, authored hazards, explicit transitions and optional square/hex grids. Protected entity metadata and private notes use World authorization and an owner-only server-redacted ordinary preview. No Player sharing or VTT/runtime state is introduced; editor layers remain presentation settings. Phase 4 and Living History map evolution remain future work.

Future System Canon marking belongs exclusively to Administrators. Future approved-canon discovery must preserve protected internal content and the ability for Administrators to inspect Worlds. Passes 3B through 3D add no canon toggle, public sharing or permission broadening.

The discriminated, versioned geometry contracts may gain explicitly validated types in future migrations. Existing 3A feature and geography identities, and 3B drawing identities, must survive extension. World-root authorization and revision checks remain authoritative across future scale connections.
