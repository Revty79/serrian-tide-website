# Dedicated future Atlas tools

The user's permanent requirement is connected geographic scales: World → Continent → Region → City → Building → Dungeon Floor. Pass 3B implements continent cartography only. Scope labels do not establish these links, geographic distances or nested navigation.

Each future increment must independently deliver usable tools, complete migrations, preserved data, authorized server behavior and verified desktop/phone workflows. Stable World geography/location identities remain separate from map drawings and from the visual representation's scale.

1. Secure raster backgrounds: durable authenticated asset storage, file/size validation, private delivery, overlays, restoration and deployment persistence. Never infer vector objects from baked-in artwork. This remains a separate contained increment.
2. Pass 3C implements configured seeded generation and supported description interpretation using the same editable polygon, brush-stroke, path and label contracts. Creation provenance remains separate from manually edited source. No incompatible generated picture representation. See [native generation](worlds-atlas-generation.md).
3. Pass 3D adds [connected geography and exploration](worlds-atlas-navigation.md), using shared place IDs, represented-map associations and preferred connections. Dedicated city authoring belongs to Pass 3E: editable streets, buildings, walls, districts and landmarks. Preserve existing Heavens Town, Shop and NPC ownership rather than duplicate their authoring systems.
4. Dedicated building-interior authoring: editable floor layouts, room identities, entrances and connections to their World location/building map.
5. Dedicated dungeon authoring: editable rooms, corridors, doors, stairs, multiple levels/floors, traps, secret/G.O.D.-only elements and optional grids. Hidden/protected content requires server-side authorization and redaction; editor layer visibility and locking are not security boundaries.

Future System Canon marking belongs exclusively to Administrators. Future approved-canon discovery must preserve protected internal content and the ability for Administrators to inspect Worlds. Passes 3B through 3D add no canon toggle, public sharing or permission broadening.

The discriminated, versioned geometry contracts may gain explicitly validated types in future migrations. Existing 3A feature and geography identities, and 3B drawing identities, must survive extension. World-root authorization and revision checks remain authoritative across future scale connections.
