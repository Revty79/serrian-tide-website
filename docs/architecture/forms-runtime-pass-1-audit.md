## Storage and lifecycle decision

Use three narrowly scoped structures: immutable typed Form transition events; one current-state row per positive individual referencing its exact entry event; and durable requests for retries and pending Initiative operations. Race evidence retains exact Race/Form row ID and stable key. Creature evidence retains exact Creature identity, frozen snapshot digest and snapshot-local Form ID/key. Typed columns/checks keep the two identity domains distinct; historical evidence survives later library Form edits/removal.

No row means Normal. No migration backfill infers active state from previews or references. Return ends the active entry, rather than restoring a whole Character snapshot. Events retain frozen definitions, Access/facts, authority/rulings, timing/cost results and copied runtime context. Campaign graph deletion must explicitly include these records; ordinary historical mutation remains disallowed.

Entry costs are paid once when a supported timed transition starts. Actual active state changes when its pending action finishes at a clean boundary. If other unfinished involvement remains, the completed timing waits for a clean completion review; no additional resource spend or Initiative charge occurs. Cancellation/force-end leaves the prior state and records the durable request outcome. Form state has no automatic duration, trigger, limit-refresh or cooldown executor in Pass 1.

An active Form or pending transformation blocks permanent Evolution/Return until Normal with no pending transformation. Existing Normal Evolution remains intact. Combat source locking will record the current Form identity as evidence after acquiring existing runtime locks, while continuing to execute Normal mechanics. UI must state that Form mechanics arrive in Pass 2 and automatic expiry/limits remain pending Pass 3.

All schema rehearsal and database/browser tests use disposable localhost databases. No configured shared database or Production migration is authorized. Stop after Pass 1; no push or automatic Pass 2.
